\begin{defn}[Predicates and Quantifiers]
    A \emph{predicate}\index{predicate} is a statement containing a finite number of variables. The predicate becomes true or false based on the value of the variables.  The variables may be specific values or elements of a set.  If a predicate is always true, or always false, this may be indicated with the \emph{universal quantifier, \(\forall\)}, which is read ``for all''.  If it is true for selected values we use the \emph{existential quantifier, \(\exists\)}, which is read as ``there exists''.
\end{defn}

\begin{exposition}[Truth Sets]

Given a predicate, the \emph{truth set}\index{truth set} for that predicate is the collection of all elements where it is true.  For example for \(V(x): x\ \text{is a vowel}\), the truth set is 
    \[T_V=\left\{a,e,i,o,u,y\right\}\] and for \(P(x): x\ \text{is a pentagon}\) the truth set is \[T_P=\left\{t,a,u,h,k,o,p\right\}.\] 
Figure \ref{fig:VP_Venn} shows how these two sets are related, in particular we can see that 
    \[V(x)\wedge P(x)\ \text{and}\ V(x)\wedge \sim P(x)\ \text{and}\ \sim V(x)\wedge P(x)\]
are all true if we pick the right value of \(x\).

\begin{figure}[H]
    \centering
    % \inputtikz{truth_set_venn}
    \includegraphics[scale=0.24,alt={Venn diagram of two truth sets},width=0.75\linewidth]{images/created/truth_set_venn.png}
    \caption{Venn Diagram of \(T_V\) and \(T_P\)}
    \label{fig:VP_Venn}
\end{figure}

\noindent
The predicates like \[W(x,y):\, x\ \text{is in the same row as}\ y\]
would have the truth set like
\[T_W=\left\{(e,h),(h,e),(u,p),(p,u),(i,k),(k,i),(a,d),(d,a),(t,o),(o,t)\right\},\]
consisting of ordered pairs.
\end{exposition}

\begin{exposition}[Quantified Predicates]
% Examples
Recall \(\exists\) is the \emph{existential quantifier}\index{existential quantifier} and \(\forall\) the \emph{universal quantifier}\index{universal quantifier}.  Now, if we write 
    \[\exists x: V(x)\wedge P(x)\]
we can read that as 
\begin{center}
    \textit{``there exists a vowel which is also a pentagon''}
\end{center} 
or in plainer English 
\begin{center}
    \textit{``some vowels are pentagons.''}
\end{center} 
Is the previous statement true or false? How can we see it in the Venn Diagram in figure \ref{fig:VP_Venn}?\vspace{3\baselineskip}

\noindent
And, if we write 
    \[\forall x: V(x)\vee P(x)\]
we read it as 
\begin{center}
    \textit{``all the shapes are vowels or pentagons.''}
\end{center} Is this true or false? How can we see it in the Venn diagram in figure \ref{fig:VP_Venn}?\vspace{3\baselineskip}

\noindent
In addition to using them one at a time we can combine quantifiers like so 
    \[\forall x\,  \exists y: C(x)\rightarrow L(x,y),\] 
which we read as 
\begin{center}
    \textit{``every consonant shares a column with some letter,''}
\end{center} or like this \[\exists y\, \forall x: C(x)\rightarrow L(x,y)\] which we read as 
\begin{center}
    \textit{``some letter shares a column with every consonant.''}
\end{center} Which of the previous two statements is true and which is false?  How do we know?\vspace{3\baselineskip}
\end{exposition}

\begin{exposition}[A Couple Comments on Quantifiers]

    As we have seen in the examples above the negation of a universal quantifier is an existential and vice versa:
    \[\sim\left(\forall x:P(x)\rightarrow Q(x)\right) \equiv \exists x: P(x) \wedge \sim Q(x).\]
    With that in mind, what is the negation of ``There exists a green vowel which is also a consonant?''\vspace{40pt}
    
    How would we write each of these symbolically? \vspace{40pt}
    
    Referring to figure \ref{fig:Tarski} on \pageref{fig:Tarski}, why is the original statement always false and the negation \emph{vacuously true}?\vspace{40pt}

    
    The ways in which we represent ideas with quantifiers are not unique.  Here are some examples of equivalent statements from practice problem \ref{prob:tarski_zombies} which use the predicates for figure \ref{fig:Tarski} on page \pageref{fig:Tarski}.
    \begin{itemize}
        \item \(\displaystyle\forall x: H(x)\rightarrow C(x)\) can be written \[\forall x\in T_H: C(x).\]
        \item \(\displaystyle\exists x: V(x)\wedge R(x)\) can be written \[\exists x\in T_V: R(x).\]
        \item \(\displaystyle\forall x\, \exists y: C(x)\rightarrow V(y)\wedge L(x,y)\) is equivalent to 
            \[\forall x: C(x)\rightarrow \exists y: V(y)\wedge L(x,y).\]
        \item \(\displaystyle\exists y\in T_N, \forall x\in T_Z: W(x,y)\) is the same as 
            \[\exists y: N(y) \wedge \forall x: Z(x)\rightarrow W(x,y)\] and 
            \[\exists y \forall x: N(y) \wedge Z(x) \rightarrow W(x,y).\]
    \end{itemize}
    When looking at these and similar examples it is helpful to think of \emph{for all} statements as frequently relating to inclusion or equivalence and \emph{there exists} statements as overlap.  Try making some of these types of statements either with you examples from practice problem \ref{prob:tarski_zombies} or using the Venn Diagram in figure \ref{fig:vennimplication} on page \pageref{fig:vennimplication}.
\end{exposition}
