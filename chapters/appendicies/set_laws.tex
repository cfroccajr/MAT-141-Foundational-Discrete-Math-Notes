In the tables on the following pages:
\begin{enumerate}
	\item[(a)] $A$, $B$, $C$, $X$, $\Gamma$, and $A_\gamma$, for each $\gamma\in\Gamma$ are all sets.
	\item[(b)] \familySet is a set of sets.
	\item[(c)] \uniSet is the universal set (i.e. a set containing all the elements under consideration).
	\item[(d)] $p(x)$ is a statement about the variable $x$.
\end{enumerate}
